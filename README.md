# Duo Detailing website

Static website for Duo Detailing (Hoboken, NJ and Long Island, NY). Hosted free on GitHub Pages.

## Files
- `index.html` – home page
- `services.html`, `pricing.html`, `areas.html`, `contact.html` – other pages
- `style.css` – all styling (colors are at the top under `:root`)
- `script.js` – mobile menu and footer year

## Things to replace before going live
- Phone, email and hours (in the footer of every page, plus `contact.html`)
- Prices (`$XX`) in `pricing.html`
- Real customer reviews and your story on `index.html`
- Placeholder photo boxes (`class="shot"`) with your own images, e.g. `<img src="images/car1.jpg" alt="Detailed black SUV">`. Put images in an `images/` folder.
- Form ID in `contact.html` (see the comment there; uses Formspree)
- Town lists in `areas.html`
